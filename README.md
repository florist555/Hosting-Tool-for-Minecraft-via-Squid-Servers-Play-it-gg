How to use the Hosting tool
1. locate folder and open in cmd
2. python main.py
3. click settings on the bottom left
4. browse server folder of minecraft


How to setup rclone
1. download rclone and put beside the application (or if you had downloaded the zip file compile all of them in one)
2. then in the file explorer, type cmd and open the folder in cmd
3. then type rclone config and log in using your cloud storage service account
4. after connecting, it will allow you to sync and multi host using your cloud storage account
